Course Overview

This course introduces the fundamental concepts of structured programming using the C programming language. Students will develop programming logic and learn to create programs and applications using C. The course covers flow control, functions, arrays, strings, pointers, dynamic memory allocation, structures, file operations, and competitive programming problem solving.

By the end of this course, students will be able to:

  • Understand the basic programming concepts and terminology related to structured programming languages.
  • Explain different programming concepts including flow control, functions, arrays, strings, pointers, structures, and file handling.
  • Analyze different problem scenarios and determine suitable programming solutions.
  • Apply C programming syntax and structures to solve different types of computational problems.
  • Develop logical and algorithmic thinking for competitive programming problems.

Schedule

Week Date Topic Materials
1 Week 1 Introduction to C Programming

Overview of structured programming and introduction to C programming, including character sets, C tokens, keywords, identifiers, data types, variables, constants, and type casting.
2 Week 2 Operators and Expressions

Study of arithmetic and logical operators, operator precedence and associativity, type conversion in expressions, conditional operators, library functions, and input-output functions.
3 Week 3 Control Statements

Introduction to decision-making and looping structures including if-else statements, if ladders, nested if-else, for loops, while loops, and do-while loops.
4 Week 4 Nested Loops and Problem Solving

Analysis and implementation of nested loops and solving real-world programming problems using iterative techniques and appropriate loop structures.
5 Week 5 Break, Continue, GOTO and Functions

Study of break, continue, and GOTO statements, comma operator, function prototypes, function calls, and return statements.
6 Week 6 Functions, Parameters and Recursion

Practical study of function calls with different parameters, passing arguments to functions, recursive functions, and direct recursion.
7 Week 7 Midterm Review and Case Study

Review of the topics covered during the first six weeks through case studies, problem-solving activities, questions and answers, and examination preparation.
8 Week 8 Arrays

Introduction to arrays, array declaration and initialization, array traversal, passing arrays to functions, array operations, and multidimensional arrays.
9 Week 9 Strings and Character Processing

Study of arrays and strings, string input and output, ASCII values, character frequency, counting characters, and binary strings.
10 Week 10 String Manipulation

Practical implementation of string copying, comparison, reversal, and concatenation using standard library functions.
11 Week 11 Pointers

Introduction to pointers, pointer declarations, passing pointers to functions, pointers and one-dimensional arrays, pointers and strings, and string operations.
12 Week 12 Dynamic Memory Allocation and Structures

Study of dynamic memory allocation using malloc, calloc, and realloc, arrays of pointers, structure definition, structure processing, member access, and structure initialization.
13 Week 13 File Handling

Introduction to declaring, opening, processing, and closing files. Practical use of fscanf(), fgets(), fread(), and other file operations.
14 Week 14 ACM-ICPC and Online Judge Systems

Introduction to programming contest judging systems and solving programming problems using online judges such as UVA.
15 Week 15 Competitive Programming Problem Solving

Practical problem solving using ACM-ICPC style problems and UVA programming problems with emphasis on algorithmic thinking and efficient solution development.
16 Week 16 Brainstorming and Problem-Solving Week

Intensive brainstorming, discussion, and problem-solving activities to strengthen programming logic and prepare students for the semester final examination.
17 Week 17 Final Review and Case Study

Comprehensive review of structured programming concepts through case studies, questions and answers, problem solving, and viva voce preparation for the semester final examination.
