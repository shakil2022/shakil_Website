Structured Programming Language

This course introduces the fundamental concepts of structured programming using the C programming language. Students will develop programming logic and problem-solving skills through the study of data types, operators, control statements, functions, arrays, strings, pointers, dynamic memory allocation, structures, file handling, and competitive programming techniques.

Instructor: Md. Shakil Ahmed

Term: Fall

Location: B4-405 and B3-402

Time: Mondays, 10:30-11:45 AM and Thursdays, 9:15-10:30 AM

## Course Overview

This course introduces the fundamental concepts of structured programming using the C programming language. Students will develop programming logic and learn to create programs and applications using C. The course covers flow control, functions, arrays, strings, pointers, dynamic memory allocation, structures, file operations, and competitive programming problem solving.

By the end of this course, students will be able to:

- Understand the basic programming concepts and terminology related to structured programming languages

- Explain different programming concepts including flow control, functions, arrays, strings, pointers, structures, and file handling

- Analyze different problem scenarios and determine suitable programming solutions

- Apply C programming syntax and structures to solve different types of computational problems

- Develop logical and algorithmic thinking for competitive programming problems

Introduction to decision-making and looping structures including if-else statements, if ladders, nested if-else, for loops, while loops, and do-while loops.

Analysis and implementation of nested loops and solving real-world programming problems using iterative techniques and appropriate loop structures.

Study of break, continue, and GOTO statements, comma operator, function prototypes, function calls, and return statements.

Practical study of function calls with different parameters, passing arguments to functions, recursive functions, and direct recursion.

Review of the topics covered during the first six weeks through case studies, problem-solving activities, questions and answers, and examination preparation.
