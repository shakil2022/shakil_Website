## Course Overview

This laboratory course provides students with practical experience in designing, creating, modifying, and managing relational database systems. The course is based on CSE 207: Database Management Systems and focuses on the practical implementation of database concepts using SQL and relational database management systems.

By the end of this course, students will be able to:

- Demonstrate the use of a relational database management system to create, secure, populate, and maintain databases.

- Apply SQL commands to create and modify database structures.

- Perform data manipulation operations, including insertion, deletion, and updating of records.

- Design and execute SQL queries using selection, projection, restrictions, joins, grouping, and subqueries.

- Implement database constraints, indexes, views, and triggers.

- Design relational databases and develop ER diagrams for real-world applications.

- Develop a database application using a relational database management system.

- Demonstrate teamwork, problem-solving, and project management skills through a database project.
