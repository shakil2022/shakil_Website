**## Course Overview**

This laboratory course provides hands-on experience in applying software engineering principles and techniques to practical software projects. By the end of this course, students will be able to:

\- Apply software development process models and Agile methodologies to software projects

\- Analyze and document software requirements using appropriate techniques

\- Develop UML models including Use Case, Activity, Class, State, and Sequence Diagrams

\- Design software architecture and apply suitable software design patterns

\- Implement software systems using structured and maintainable development practices

\- Develop and execute software testing strategies and evaluate software quality

\- Apply configuration management, project management, software metrics, and estimation techniques

**## Prerequisites**

\- CSE 327: Software Engineering

\- Basic programming knowledge

\- Basic understanding of software development processes

\- Familiarity with object-oriented programming concepts

**## Textbooks**
